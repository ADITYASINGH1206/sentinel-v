## 1. Executive Summary & Deliverables

Milestone M10 delivers the complete end-to-end evaluation harness and publication artifact pipeline for **Paper B** (*"Calibrated and Auditable Video Deepfake Screening: From Detector Scores to Accountable Moderation Decisions"*).

The harness benchmarks the SENTINEL-V screening architecture across multi-dataset standards, operational base rates ($\pi \in [0.1\%, 20\%]$), two-stage cascade Pareto trade-offs, in-the-wild perturbation chains, explanation faithfulness, longitudinal drift monitoring, and cryptographic auditability overheads.

### Deliverables Produced:
1. **Evaluation Manifests (`eval/manifests/`):**
   - `faceforensics_c23.jsonl` (30 records, FaceForensics++ c23)
   - `deepfake_detection.jsonl` (30 records, Deepfake Detection benchmark)
   - `celeb_df_v2.jsonl` (30 records, Celeb-DF v2 in-the-wild benchmark)
2. **Score Extraction CLI (`tools/dump_scores.py`):**
   - High-throughput batch inference CLI parsing JSONL manifests, applying S-MSDT-S / S-MSDT-ST cascade policies, and outputting structured scores (`video_id`, `u_score`, `p_bal`, `decision_band`, `stage_reached`, `runtime_ms`).
3. **Paper B Experiment Suite (`eval/scripts/experiments/`):**
   - `e1_parity.py`: Serving pipeline vs upstream research parity check.
   - `e2_base_rates.py`: Base rate prevalence sweeps across $\pi \in [0.1\%, 20\%]$, reproducing SPEC §7.4 benchmarks.
   - `e3_cascade.py`: Two-stage cost cascade Pareto frontier optimization.
   - `e4_robustness.py`: In-the-wild perturbation degradation chains (CRF 28/35, 480p, 15fps, messaging apps, screen capture).
   - `e5_latency_cost.py`: Hardware latencies (p50/p95), peak VRAM, parameter counts, and AWS GPU screening dollar costs.
   - `e6_calibration_transfer.py`: Target-domain recalibration efficiency under sample budgets $N \in \{25, 50, 100, 200, 500\}$.
   - `e7_ablations.py`: Serving pipeline ablations ($K \in \{1, 2, 4, 8\}$ clips, window durations, aggregation rules).
   - `e8_fusion_generative.py`: Multi-modal fusion vs modern text-to-video diffusion generation (Sora, Runway Gen-2, Pika v1).
   - `e9_faithfulness.py`: Spatiotemporal patch explanation faithfulness (pointing game accuracy, top-10% IoU, deletion AUC, insertion AUC).
   - `e11_drift.py`: 30-day operational domain drift trajectory tracking 10-quantile PSI, IPW ECE, and governed recalibration.
   - `e12_receipts.py`: Detection Receipt cryptographic audit overhead (Merkle tree depth, proof bytes, Ed25519 signing/verification latencies, EVM gas benchmarks).
4. **Master Orchestrators (`eval/scripts/`):**
   - `run_experiment.py`: Single experiment driver (`python eval/scripts/run_experiment.py --id <e1..e12>`).
   - `run_all.py`: End-to-end execution of all 11 experiments with automated output validation.
5. **Publication-Grade Vector Figures (`eval/figs/`):**
   - `roc.py` $\to$ `fig_roc.pdf`, `fig_roc.svg`: Multi-chain ROC curves with AUC annotations.
   - `cascade_pareto.py` $\to$ `fig_cascade_pareto.pdf`, `fig_cascade_pareto.svg`: Compute savings vs TPR @ 1% FPR Pareto frontier.
   - `drift_timeline.py` $\to$ `fig_drift_timeline.pdf`, `fig_drift_timeline.svg`: 30-day longitudinal PSI and IPW ECE trajectory.
   - `base_rate_curves.py` $\to$ `fig_base_rates.pdf`, `fig_base_rates.svg`: Empirical Precision (PPV) and Workload vs Prevalence.
   - `robustness_radar.py` $\to$ `fig_robustness_radar.pdf`, `fig_robustness_radar.svg`: Polar perturbation degradation radar chart.
   - `render_all.py`: Master figure renderer generating all vector figures directly from evaluated CSVs.
6. **Automated Test Suite (`eval/tests/test_eval_harness.py`):**
   - 15 comprehensive unit and integration tests verifying manifests, dump CLI, all 11 experiment runners, CLI deferral handling, and vector figure outputs.
