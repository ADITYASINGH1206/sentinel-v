## 1. Summary of What Was Built

1. **Relational Database & Models (`sv_api.database`, `sv_api.models`):**
   - Asynchronous SQLAlchemy 2.0 models for `User`, `ApiKey`, `Media`, `AnalysisModel`, `TrackModel`, `ReviewModel`, and `AuditLog`.
   - SQLite asynchronous engine for testing and PostgreSQL/asyncpg support for production.

2. **Authentication & Authorization (`sv_api.auth`):**
   - Argon2id password hashing and verification.
   - JWT token generation and validation.
   - `sv_live_` API key hashing and validation with SHA-256 storage.
   - Immutable audit logging for security-sensitive actions.

3. **Celery Task Pipeline (`sv_workers.tasks`):**
   - `ingest.py`: SHA-256 media hashing and 30-day deduplication cache check.
   - `preprocess.py`: Video preprocessing invocation and NPZ track serialization.
   - `gpu.py`: Model inference over tracks, decisive track identification, and idempotent DB persistence.
   - `finalize.py`: Platt calibration scaling, prior prevalence adjustments, decision banding, and Ed25519 receipt generation.
   - `utils.py`: Safe thread-isolated async loop runner (`run_async`).

4. **Real-Time SSE Streaming & REST API (`sv_api.sse`, `sv_api.routes`):**
   - Redis Pub/Sub SSE progress broadcaster with in-memory queue fallback for offline test environments.
   - `POST /v1/analyses`: File and URL submission with 202 Accepted response.
   - `GET /v1/analyses/{id}`: Calibrated score, decision band, and signed receipt retrieval.
   - `GET /v1/analyses/{id}/events`: Server-sent events streaming pipeline stage progress.
   - `GET /v1/analyses/{id}/evidence`: Evidence package and overlay retrieval.
