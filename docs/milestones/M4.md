## 1. Summary of What Was Built

1. **Patch Evidence Map Reshaping & Upsampling (`packages/sv_engine/src/sv_engine/evidence.py`):**
   - Implemented `reshape_patch_logits_to_map`: transforms $(K, T, P)$ token logits where $P = \text{grid}^2$ (e.g. $14 \times 14 = 196$) into $(K, T, \text{grid}, \text{grid})$.
   - Applied sigmoid non-linearity to map raw patch logits to a continuous $[0, 1]$ probability range.
   - Performed bilinear upsampling from grid dimension to $224 \times 224$ (the face crop core area) and symmetric 16-pixel reflection padding to produce $256 \times 256$ crop-space heatmaps matching the aligned crop dimension.

2. **Sub-pixel Coordinate Back-Projection:**
   - Implemented `invert_affine_matrix`: computes the exact $2 \times 3$ inverse similarity matrix $M^{-1}$ from the forward face crop affine transform $M$.
   - Implemented `warp_heatmap_to_source_frame`: projects the $256 \times 256$ crop-space heatmap back to original source video coordinates $(W, H)$ via `cv2.warpAffine` using linear interpolation (`cv2.INTER_LINEAR`).
   - Verified that round-trip geometric mapping error $(x, y) \to M \to M^{-1} \to (x', y')$ is strictly $< 0.1$ px (well within the SPEC §8.2 tolerance of $< 0.5$ px).

3. **Perceptually Uniform Color Mapping:**
   - Implemented `apply_colormap_magma`: maps continuous $[0, 1]$ patch probabilities to the sequential `magma` colormap (dark purple $\to$ red $\to$ yellow).
   - Applied a fixed global $[0, 1]$ scale across all frames to prevent perceptual flicker and temporal drift.
   - Enforced an alpha transparency floor at 0.15 ($p < 0.15$ is fully transparent; $p \ge 0.15$ linearly ramps from 0.15 to 1.0) so non-manipulated face regions remain unobstructed.

4. **Reviewer Artifact Generation (`packages/sv_engine/src/sv_engine/overlay_render.py`):**
   - Implemented `save_webp_frame`: exports transparent RGBA WebP heatmaps with 720p maximum resolution cap and computes individual SHA-256 digests.
   - Implemented `draw_score_banner`: burns in top audit header with calibrated score ($p$) and decision band (`likely_authentic`, `needs_review`, `likely_manipulated`, or `inconclusive`), alongside bottom footer with mandatory disclaimer: `"Screening aid — not proof. Human review required for consequential action."` (compliant with SPEC §14.13).
   - Implemented `render_overlay_video`: composites alpha-blended evidence maps over source frames, caps output resolution at 720p, encodes to MP4 (`avc1`/`mp4v`), and computes file SHA-256 digest.
   - Implemented `write_manifest_json`: generates structured JSON manifest linking all artifact relative paths, frame metadata, track IDs, and cryptographic digests.

5. **Cryptographic Evidence Merkle Root & Pipeline Integration:**
   - Implemented `compute_evidence_root`: constructs a Merkle tree over the SHA-256 digests of all generated evidence artifacts (WebP frames, overlay MP4, manifest) using `sv_receipts.merkle.MerkleTree`.
   - Wired evidence extraction and artifact rendering into Celery GPU worker task (`services/workers/src/sv_workers/tasks/gpu.py`).
   - Propagated the decisive track's `evidence_root` through `AnalysisModel.signals` into `finalize.py` for inclusion in the Ed25519-signed detection receipt.
