## 1. What Was Built

### 1.1 Statistical Drift Engine (`services/monitor/src/sv_monitor/drift.py`)
- **Quantile Binning Baseline (`compute_quantile_bins`):**
  - Derives 10 quantile bins from reference validation scores (`reference_scores.parquet` or validation array).
  - Handles real-line bounds by setting boundary edges to $(-\infty, \infty)$ for robust continuous binning.
- **Continuous Population Stability Index (`compute_psi`):**
  - Implements standard formulation:
    $$\text{PSI} = \sum_{b=1}^{10} (\tilde{P}_b - \tilde{Q}_b) \times \ln\left(\frac{\tilde{P}_b}{\tilde{Q}_b}\right)$$
  - Applies Laplace smoothing ($\epsilon = 10^{-4}$) to prevent numerical zero division or $\ln(0)$.
  - Maps to compliant status thresholds:
    - $\text{PSI} < 0.10 \implies$ `ok`
    - $0.10 \le \text{PSI} \le 0.25 \implies$ `watch`
    - $\text{PSI} > 0.25 \implies$ `alert`
  - Returns per-bin contribution breakdown and boundary points.
- **Categorical Feature Drift (`compute_categorical_psi`):**
  - Evaluates shift in discrete features (e.g. video container formats, video codecs).
- **Multi-Feature Input Drift Monitor (`evaluate_input_drift`):**
  - Evaluates scores, face bounding box size, detector confidence, FPS, resolution, and codecs.
  - Returns composite `FeatureDriftSummary` with worst-case aggregated health alert status.
- **Inverse-Probability Weighted ECE (`compute_ece_ipw`):**
  - Evaluates rolling 30-day calibration across 15 equal probability bins in $[0, 1]$.
  - Applies inverse-probability sample weighting ($w_i = 1 / \pi_i$) correcting for review queue selection bias between 100%-reviewed flagged items ($w=1.0$) and randomly audited samples ($w = 1 / \text{audit\_sample\_rate} \approx 50.0$).
  - Outputs weighted accuracy, weighted confidence, calibration error per bin, weighted Brier score, and weighted Log-Loss.

### 1.2 Governed Model Recalibration Pipeline (`services/monitor/src/sv_monitor/recalibration.py`)
- **Ground-Truth Precondition Guards (`propose_recalibration`):**
  - Strictly requires $N \ge 200$ expert reviews.
  - Strictly requires $\min(N_{\text{authentic}}, N_{\text{manipulated}}) \ge 50$ to avoid degenerate uncalibrated fittings.
  - Raises `InsufficientDataError` with explicit count diagnostics if criteria fail.
- **Candidate Parameter Optimization:**
  - Fits class-balanced Platt parameters $(A_{\text{new}}, B_{\text{new}})$ using `sv_engine.calibration.fit_platt`.
  - Computes side-by-side reliability diagrams (15 bins) and confusion matrices at policy thresholds ($\tau_{\text{auth}}=0.35, \tau_{\text{manip}}=0.75$) before and after recalibration.
  - Calculates net calibration change $\Delta \text{ECE}$, Brier score, and Log-Loss.
- **Auditable Governance & Immutability (`promote_recalibration`):**
  - Requires written admin justification ($\ge 20$ characters) documenting drift rationale.
  - Produces unique `calibration_id`, target bundle version, and cryptographic SHA-256 bundle digest.
  - Enforces immutable versioning: previous calibrations are never overwritten.

### 1.3 Automated Data Retention Engine (`services/monitor/src/sv_monitor/retention.py`)
- **Automated Lifecycle Purge (`run_retention_policy`):**
  - Purges raw media older than 30 days (`SV_RETENTION_MEDIA_DAYS = 30`), updating `Media.deleted = True` and clearing storage references.
  - Purges evidence artifacts (WebP frame heatmaps, overlay MP4s) older than 180 days (`SV_RETENTION_EVIDENCE_DAYS = 180`).
- **Detection Receipt Preservation Invariant:**
  - Verifies and guarantees that all cryptographic Detection Receipts (`analyses.receipt_id`) and Merkle tree root hashes remain permanently preserved for auditability and non-repudiation.

### 1.4 REST API Endpoints (`services/api/src/sv_api/routes/monitor.py`)
- `GET /v1/monitor/drift`: Returns latest continuous and categorical PSI drift summary.
- `GET /v1/monitor/calibration`: Returns rolling 30-day IPW ECE and 15-bin reliability diagram.
- `POST /v1/models/{model_id}/recalibrations`: Generates candidate recalibration proposal with side-by-side diagnostics.
- `POST /v1/models/{model_id}/recalibrations/{proposal_id}/promote`: Admin-promoted recalibration requiring written justification.
- `POST /v1/monitor/retention/run`: Triggers automated retention policy execution and returns audit purge report.
