## 1. Summary of What Was Built

1. **Model Adapters (`sv_engine.adapters`):**
   - `clip_st.py`: Stage B spatiotemporal detector (`CLIPFrameEncoder` + `SMSDTv2`, $T=16$ or $T=8$, CLIP normalization).
   - `clip_s.py`: Stage A single-frame spatial detector ($T=1$, CLIP normalization).
   - `cnn_p1.py`: Phase 1 EfficientNet-B4 + Haar DWT + DensePSIT ($[0, 1]$ tensor normalization without mean/std subtraction).
   - `full_c.py`: Stage C adapter with Blocker B1 guard (`NotImplementedError` until v3 modules upstream).
   - Strict state dict loading: verifies `missing_keys == []` and `unexpected_keys == []`.

2. **Model Bundle Builder & Verifier (`tools/make_bundle.py`):**
   - Bundles weights in `.safetensors` format with offline HuggingFace CLIP vision config (`clip_config.json`).
   - Generates and verifies `checksums.sha256` for all bundle assets, refusing startup on any tampered or missing asset.
   - Generates bundle metadata, calibration parameters (`calibration.json`), and operating points (`operating_points.json`).

3. **Calibration Fitting Tool (`tools/fit_calibration.py`):**
   - Class-balanced Platt scaling fitting ($a, b$) on validation logits using L-BFGS-B optimization.
   - Calculates Youden-optimal threshold $\tau^*$, 15-bin Expected Calibration Error (ECE), and operational TPR metrics at fixed FPR budgets (1% and 5%).

4. **Parity Check Verification Harness (`tools/parity_check.py`):**
   - Evaluates parity between serving adapters and research evaluation scripts (`smsdt.eval_cross`) with strict tolerances (median $|\Delta u| \le 0.05$, p95 $\le 0.20$, AUC difference $\le 0.005$).
