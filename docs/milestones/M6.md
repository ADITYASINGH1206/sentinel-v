## 1. Summary of What Was Built

1. **Two-Stage Cost Cascade Engine (`packages/sv_engine/src/sv_engine/cascade.py`):**
   - Implemented `evaluate_cascade`: runs cheap Stage 1 (S-MSDT-S, $T=1$), calibrates logit $u_1 \to p_1 = \sigma(a_1 u_1 + b_1)$, and checks early-exit condition ($p_1 < \text{exit\_below\_p\_bal}$).
   - Early exit saves full 8-frame ViT computation on clearly authentic clips. Ambiguous and suspicious clips escalate to Stage 2 (S-MSDT-ST or Full, $T=8$) producing final $p_{\text{bal}}$.
   - Multi-track aggregation: video logit $u(V) = \max_j u_j$, decisive track = $\arg\max_j u_j$.
   - Compliant decision band mapping (`assign_decision_band`): maps calibrated probability to `likely_authentic`, `needs_review`, `likely_manipulated`, or `inconclusive` (zero bare FAKE/REAL strings per SPEC §14.13).

2. **Cascade Threshold Optimization Sweep (`tools/fit_cascade.py`):**
   - Implemented `sweep_cascade_thresholds`: grid sweep algorithm over candidate exit cutoffs $t \in [0.01, 0.50]$.
   - Strictly enforces constraints:
     1. Validation fake leakage $\le 1.0\%$ (fakes early exiting on Stage 1).
     2. Stage 2 decision agreement $\ge 99.0\%$ on escalated samples.
   - Selects optimal cutoff maximizing early exit compute savings ($\sim 28\text{--}65\%$ compute reduction).

3. **Standard Decision Policy Presets:**
   - Implemented `POLICY_PRESETS`:
     - `strict-low-fpr`: In-domain low base rate ($\pi=0.01$), Stage 1 S $\to$ Stage 2 ST, $\tau_{\text{auth}}=0.30, \tau_{\text{manip}}=0.75, \text{exit}=0.12$.
     - `transfer-calibrated`: Cross-dataset transfer ($\pi=0.05$), Stage 1 S $\to$ Stage 2 Full/ST, $\tau_{\text{auth}}=0.35, \tau_{\text{manip}}=0.70, \text{exit}=0.15$.
     - `evidence-desk`: Forensics desk mode ($\pi=0.20$), full ST on all tracks, cascade disabled, $\tau_{\text{auth}}=0.40, \tau_{\text{manip}}=0.60$.

4. **Prevalence-Aware Policy Simulator Engine (`tools/simulate_policy.py`):**
   - Implemented `simulate_policy`: calculates flags per 10k, true positives, false positives, missed fakes, PPV (Precision), and reviewer workload hours per day.
   - Implemented `simulate_model_preset`: maps model variants to measured operating characteristics from Paper A Table 2.2.
   - Exact benchmark match: At $\pi=0.01$ (1% prevalence), Full model @ 1% FPR yields **138 flags per 10k** and **28.47% (~28.5%) PPV**, perfectly matching SPEC §105 / §7.4.
   - Implemented `sweep_prevalence_curve`: sweeps prevalence from 0.1% to 20% demonstrating monotonic precision scaling.

5. **REST API Endpoints (`services/api/src/sv_api/routes/policies.py`):**
   - `GET /v1/policies/presets`: Returns built-in presets.
   - `GET /v1/policies`: Lists all configured policies.
   - `GET /v1/policies/{policy_id}`: Retrieves specific policy configuration.
   - `POST /v1/policies`: Registers or updates policy with automatic version increment.
   - `POST /v1/policies/simulate`: Runs prevalence-aware simulation and sweeps.
