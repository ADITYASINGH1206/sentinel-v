# Parity Verification Skill

This skill guides verification of numerical equivalence between the production serving engine and the upstream research evaluation (`smsdt/eval_cross.py`) on reference GPU hardware.

## Context & Purpose
Before deploying real model scores or building UI features on production checkpoints, the serving pipeline must reproduce upstream research scores within tight tolerances. Never deploy models that have not passed this gate.

---

## Tolerances (SPEC §6.9 Gate for Milestone M2)

| Metric | Tolerance Target | Failure Consequence |
|---|---|---|
| **Per-video score difference** $|\Delta u| = |u_{\text{serve}} - u_{\text{research}}|$ | **Median $\le 0.05$**, **p95 $\le 0.20$** | Investigation of decode/alignment drift |
| **Subset Macro AUC Difference** | **$\le 0.005$** | Model output divergence |
| **Decision Band Flips at $\tau^*$** | **0 flips** unless $|u - \tau_{\text{logit}}| < 0.1$ | Gate fails |
| **Crop SSIM Parity** | **Median $\ge 0.98$** | Preprocessing divergence |

---

## Verification Workflow

### Step 1: Preprocessing & Crop Parity
Compare raw video frames processed by `packages/sv_engine/src/sv_engine/preprocess/align.py` against the upstream preprocessed store:

```bash
python3 tools/parity_check.py --mode crops --videos-dir /path/to/ffpp_c23_val --n 20
```

- Verifies that `smsdt.preprocess.align_crop.crop_frame` with `loose_template(out=256, margin=1.3)` followed by center-crop 224 matches the store tensor.
- Structural Similarity Index (SSIM) must be $\ge 0.98$ across sampled frames.

### Step 2: Full Inference Parity
Run inference on at least 50 validation videos across both research and serving pipelines:

```bash
# Research path score dump
python3 third_party/smsdt/smsdt/eval_cross.py \
  --checkpoint models/bundle-2026-11-default/smsdt-st-b/weights.safetensors \
  --dump-scores eval/results/parity/research_scores.csv

# Serving path execution
python3 tools/parity_check.py \
  --bundle models/bundle-2026-11-default \
  --research-scores eval/results/parity/research_scores.csv \
  --report eval/results/parity/parity_report.json
```

### Step 3: Inspecting Failures
If parity fails:
1. Examine `eval/results/parity/worst_cases.html` generated by `tools/parity_check.py`.
2. Compare side-by-side images of research crop vs serving crop.
3. Check for color space discrepancies (BGR vs RGB), rotation flag mismatches, or differing interpolation modes (`INTER_LINEAR` vs `INTER_CUBIC`).
